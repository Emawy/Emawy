# Firmware

[sketch_may22a/sketch_may22a.ino](sketch_may22a/sketch_may22a.ino) is the original uploaded sketch, unchanged.

Open it in Arduino IDE, select the actual controller board and port, and check availability of the Servo library. Board model and toolchain versions are TO ADD.

See the [project README](../README.md#current-status-and-known-limitations) before compiling or operating hardware. This archived version has not been compiled or tested here. In particular, cup detection has a missing return value and does not reject a zero ultrasonic reading.
